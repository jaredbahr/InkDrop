This build focused mainly on making acquisition, search, and importing more reliable. It also includes a security pass, several performance improvements, and some lighter UI work.

- **Manual Search no longer fails across every provider at once.** A locking issue meant one slow provider could prevent the other three from starting until their search time had already expired. Providers now run independently again.

- **"Use this candidate" in Manual Review now works for downloaded files.** Previously, approving an existing file could silently do nothing. It now imports the file correctly, records the manual override, and still checks for corruption and duplicates.

- **Fixed a cleanup crash that could break search, imports, and queue processing at the same time.** Duplicate-issue cleanup could fail while removing records that were still in use. Because this cleanup runs before many other operations, one failure could cause several unrelated jobs to fail behind it. Cleanup now checks whether a record is still needed before removing it.

- **Fixed an issue that could import a release into the wrong series.** Two MangaDex titles sharing an alias or creator credit could occasionally be treated as the same series.

- **Fixed Roman numeral parsing.** Filenames containing text such as "VC" could be mistaken for a volume number and assigned to volume 100.

- **Fixed unnecessary search cooldowns.** Background bookkeeping was sometimes recorded as an actual search attempt, which could incorrectly place a series into a six-hour cooldown.

- **Fixed several causes of stuck or silently failed downloads.**
  - Force Grab now works on results that were previously rejected incorrectly.
  - Soulseek transfers waiting on a busy uploader are no longer stopped after 8–10 minutes. The default timeout is now 48 hours and can be changed in Settings.
  - Autopilot no longer spends its entire run processing old catch-up work before starting anything new.
  - The first search for a newly added series is no longer swallowed by background bookkeeping.
  - One failed download-client handoff no longer stops the rest of the acquisition pass.

- **Fixed valid files being rejected.** Downloaded issues are no longer marked as the wrong series simply because their pack folder has an unbracketed name. Manga chapters containing normal volume and chapter information are also no longer blocked outright.

- **Search matching is more accurate.**
  - Numeric subtitles and possessive titles are preserved in searches.
  - The series launch year is no longer added to every issue search.
  - Results that only partially match the title of another work are less likely to be grabbed incorrectly.

- **Fixed several import problems.**
  - Multi-chapter and multi-volume downloads now import in the correct order.
  - Successful imports no longer remain stuck in the queue as incomplete.
  - Two downloads can no longer compete to import the same file.
  - Packs containing multiple series are no longer treated as one series simply because they share a folder.

- **Direct-download providers now use separate staging folders** and have a working enable/disable setting. Staging also works correctly when the source and destination are on different filesystems.

- **Security improvements:** provider credentials are no longer written to persistent storage, and a script-injection issue in search-result data has been fixed.

- **Performance improvements:** Queue, Wanted, and Blocklist should load faster on larger libraries.

- **Wanted, Queue, History, Blocklist, and Manual Review now use the new page-rendering system.** The pages work the same as before, but pagination should be noticeably faster on larger libraries. This also gives us a better base for future UI improvements.

```yaml
image: ghcr.io/jaredbahr/inkdrop:latest
```
