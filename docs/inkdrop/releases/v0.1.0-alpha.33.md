# Private Alpha Update 33 (0.1.0-alpha.33)

InkDrop can now safely use exact single-unit collected editions that do not include an issue number in the filename.

- Supports trusted one-book TPB, essential, deluxe, hardcover, library, and omnibus editions.
- Requires one canonical ComicVine issue, one active wanted row, the full series title, and matching collected-edition evidence.
- Conflicting issue, volume, range, pack, year, edition, or title evidence still blocks the grab.
- Existing quality, language, size, duplicate, download, and import safety checks remain in place.
