Two real fixes worth knowing about.

- Searches for licensed creator-credit titles (e.g. "Naoki Urasawa's Monster") now try the title people actually share files under, instead of spending the whole search budget on a title nobody uses.
- A volume/print-run marker like "v1 #19" no longer gets treated as a mismatch when it's exactly the issue you wanted — that was silently blocking real grabs.
- The System page no longer hangs on a silent "Loading..." if a request stalls; you'll see what failed instead.

**Install**
```yaml
image: ghcr.io/jaredbahr/inkdrop:latest
```
Pin this build with `ghcr.io/jaredbahr/inkdrop:0.1.03`.
