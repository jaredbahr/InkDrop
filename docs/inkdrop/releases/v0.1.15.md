## InkDrop 0.1.15

Mostly correctness work in the part of the pipeline that decides whether a downloaded file really is the thing you asked for.

- **A rejected candidate no longer blocks the good ones behind it.** When the top result was refused on its own evidence, the rest of the list went with it. Each is now judged on its own.
- **A file naming a different series can no longer satisfy a want.** Destinations are graded against what the issue requires instead of trusting the filename's claim. Subtitle-only aliases and basename-only duplicate detection were both letting the wrong book through.
- **Counters on the same screen agree.** Three tallies were counting three different things side by side, and a section summary read as a breakdown of a row count it didn't match.
- **Deleting a series sticks.** A stale watch record could quietly bring one back.
- **ComicVine series can supply a cover.** Cover injection previously read artwork only from MangaDex. Still off by default.

**Install**
```yaml
image: ghcr.io/jaredbahr/inkdrop:latest
```
Pin this build with `ghcr.io/jaredbahr/inkdrop:0.1.15`.
