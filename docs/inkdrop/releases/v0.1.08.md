v0.1.08 — since v0.1.07

This release is mostly focused on search/import reliability, better troubleshooting when something goes wrong, and some cleanup across the UI.

Acquisition & Search
Fixed manga series that release as individual issues being searched and imported as volumes. InkDrop now uses the series itself to determine how releases should be handled instead of assuming based on the provider. (#390)
Fixed Allow and retry on the Blocklist page occasionally hanging while waiting on an external API. Blocked items now also show useful details like the source filename, wanted issue, and rejection reason. (#386)
Manual Review now shows the actual SLSKD filename, wanted issue, and rejection reason. Approve, retry, and delete actions are also working properly, and pagination has been added for larger review queues. (#389)
The Test button for additional SLSKD instances now performs a real connection check instead of doing nothing. (#394)

Library & Metadata
ComicInfo.xml now includes publisher information from ComicVine for comics, manga volumes, and manga chapters. Existing files were backfilled as well, updating 2,417 archives. (#388)
Downloads coming from Suwayomi and MangaDex are now correctly identified in History instead of losing their source attribution. (#391)
Fixed a long-running import verification bug that could leave successfully imported files stuck for weeks. The verifier could get stranded on its pagination cursor, was artificially limited to one item every 30 seconds, and could stop an entire batch because of one bad entry. All three issues have been fixed. (#400)

Interface
The Series page now uses the same virtualized list as Wanted, Queue, History, Blocklist, and Manual Review, which should make large libraries much smoother to work with. (#397)
Fixed nine broken CSS rules that had been silently ignored since they were introduced, along with some layout issues on Blocklist and Manual Review. (#396)
Removed an unnecessary second calculation that was happening every time a History row rendered. (#395)
Cleaned up the Connect page: removed the confusing "Folder completion is primary" message, added clearer explanations for reader On/Off status, and changed Add Connection to match the tile style used by Indexers and Download Clients. (#399, #401)
Removed some outdated "InkDrop-owned" wording from the Download Clients page. (#399)
