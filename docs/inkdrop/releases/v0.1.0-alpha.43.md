# InkDrop 0.1.0-alpha.43

- Automatic SLSKD searches retry stale empty and temporary results after a bounded cooldown instead of leaving a useful source lane parked forever.
- Recovery work shares limited scheduler capacity with cached candidates, while new and ordinary retry work keeps its reserved share of every pass.
- Never-searched rows remain eligible even when the backlog is busy; duplicate, wrong-unit, known-bad, active, and candidate-bearing results keep their existing safety gates.
- Completed qBittorrent jobs now reconcile nested pack archives before giving up, so valid volumes can continue into import while wrong-unit and out-of-staging files remain blocked.
- Web and worker processes now reap finished child processes instead of accumulating zombies during long-running searches and background jobs.
- Activity Queue is less cluttered and keeps the operational table as the main surface.
- Blocklist shows the InkDrop series/issue separately from the blocked release and adds **Allow & Retry** for an exact release.
- About no longer repeats identical notes for adjacent alpha updates.
