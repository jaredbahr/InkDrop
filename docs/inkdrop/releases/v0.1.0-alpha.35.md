# InkDrop 0.1.0-alpha.35

Search startup, library moves, and background pack status are easier to trust.

- Startup indexing now runs inside a bounded automatic pass, so large libraries cannot take over worker startup.
- Manual Search, Prowlarr, and SLSKD share aliases and broad comic-title discovery before trying narrower queries.
- Creator names and related-series matches fail closed unless the result clearly identifies the requested series.
- Series can move between configured libraries with a guarded option to move their files too.
- About keeps the latest 10 updates in detail and groups older changes with a link to the full GitHub history.
- Healthy pack verification stays compact in the background; stalled, failed, or user-blocked work remains prominent.
