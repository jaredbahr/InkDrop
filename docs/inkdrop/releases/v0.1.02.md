Searches were running and finding nothing. Several separate faults, each enough on its own to stop a series ever getting a result. If something has sat in Wanted with no explanation, this is the build to try.

- Searches run properly again, and reuse a recent result instead of asking the network twice for the same thing.
- Volumes and chapters match correctly, and ordinary comic filenames are no longer rejected.
- A failed archive read could be remembered as "this file has no metadata" for two weeks, after which the wrong issue could be imported.
- A CBR import could crash after the file was already copied, marking a good file as bad.
- A folder of loose page images is packaged as a CBZ instead of skipped.
- qBittorrent supports API keys, and a failed login says what actually went wrong.
- MangaDex mature content is ranked, not hidden.

**Install**
```yaml
image: ghcr.io/jaredbahr/inkdrop:latest
```
Pin this build with `ghcr.io/jaredbahr/inkdrop:0.1.02`.
