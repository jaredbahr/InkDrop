# Private Alpha Update 34 (0.1.0-alpha.34)

Automatic SLSKD matching now handles trusted single-volume books and issue subtitles more reliably.

- Exact Court of Owls volume-one results can move through the normal automatic SLSKD queue.
- Files such as `Fullmetal Alchemist #007 - After The Rain` can use the trusted ComicVine issue subtitle.
- Stale issue rows, related-series names, multiple volumes, ranges, packs, omnibuses, and conflicting years still block automatic grabs.
- Source and integration work is now bundled locally so GitHub Actions runs once per QA promotion instead of once per intermediate push.
