# InkDrop 0.1.0-alpha.38

- Activity now treats an orphaned staged import as the final truth. It no longer calls the same row both stalled and still moving.
- MangaDex volume packs keep their exact chapter list so InkDrop can confirm a stalled queue row really belongs to the staged volume before recovery.
- Existing verified volumes can satisfy equivalent ComicVine and MangaDex series records instead of being downloaded again.
- Failed pack imports now update the linked task, source attempt, and queue together while preserving the staged file for guarded recovery.
- Manga CBZ files receive full archive and image validation so corrupt or truncated pages fail closed.
- `.cbz`, `.cbz.zip`, and supported plain `.zip` archives now follow the same verification and normalization rules.
- Legacy manga volumes are normalized before reader scans so Kavita can group them as one series.
