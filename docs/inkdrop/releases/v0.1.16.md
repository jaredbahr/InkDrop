## InkDrop 0.1.16

Soulseek downloads stopped. This release fixes that, and most of what else is here
is the same kind of problem: a check that was refusing the right book, or a book
that was on the shelf while InkDrop went on looking for it.

**If you use Soulseek, take this one.**

- **Soulseek searches were being thrown away after the answer came back.** The
  probe was given a fixed 30-second window regardless of how much time the pass
  actually had left — sometimes less than none. A search takes about 50 seconds,
  so the window could never hold one: InkDrop asked Soulseek, Soulseek answered,
  and the reply was discarded when the probe was cut off. It now skips the
  provider when the window cannot hold a query and searches on a pass that can.
- **An accented letter split the search term.** A title carrying an accent was cut
  at that character on Soulseek and RSS, so the plain-ASCII half never matched
  anything.
- **A peer with nothing to give is remembered, and forgiven.** Saturated Soulseek
  sources are recorded as saturated instead of being re-tried every pass, and the
  mark is dropped as soon as one of them answers again.

**Books you already had, that InkDrop kept looking for**

- **A file whose folder moved could never be found again.** Once a proof was
  retracted, nothing could relocate it, so the book was re-marked missing every
  hour for as long as it sat there.
- **Two separate checks agreed a book was gone because they shared one blind
  spot.** They now have to disagree independently before a book is written off.
- **A library scan that ran out of rows never went back for the rest.** The pass
  was ordered by a timestamp that never moved, so the same rows were checked every
  time and the ones below the cut were never revisited.
- **Silence from the watcher is no longer read as arrival**, and a re-verify that
  compared a record against its own timestamp no longer waits forever.

**Getting the right book**

- **A number in a filename is no longer assumed to be an issue number.** A part
  index inside a volume, a scanner's credit at the end of a release name, a
  trailing year belonging to a different series, and a series title ending in a
  letter were each being read as the unit number or as a match.
- **A pack now proves it holds what you asked for.** Collections that declare
  their own range are checked against that range instead of being refused on the
  title alone.
- **The year inside a file's own metadata can no longer refuse the right book**,
  and a credit one reader learns is now known to all three.

**Downloads and clients**

- **The category InkDrop sends is one it also accepts.** Sent and accepted
  categories had drifted apart, so InkDrop could hand a client a job and then
  decline to recognise it.
- **SABnzbd and qBittorrent are asked about InkDrop's own categories** rather than
  whatever the client happened to list most recently.

**Searching**

- **A pass that cannot afford a full search declines it instead of running a
  truncated one.** A half-funded search reads as a genuine no-result and stops the
  hunt.
- **The fast lane no longer holds its only slot for the newest series**, so older
  wants are not starved behind whatever was added last.

**Review queue**

- **A search that finds nothing safe goes to Wanted instead of asking you.** Nothing was
  downloaded and there is no decision only a person can make, so there is nothing
  to review.
- **A review row retires when its book arrives**, a placeholder series is no
  longer offered as a retry target, and the Needs Attention card no longer
  contradicts itself.

**Settings, backup and restore**

- **Restoring a settings backup works again.** The file the browser downloaded was
  hashed in one form and checked in another, so a backup taken after saving
  certain numeric settings failed its own checksum on the way back in. The
  checksum is now taken over the form actually written to the file.
- **Restoring a backup is reachable again.** It is gated on the system being idle
  rather than switched off.
- **Opening a Settings area waits for it to load instead of racing it**, and a
  queue sync no longer wipes provider metadata from every series it touches.
- **The series list has an alphabet rail** that tracks the current letter and runs
  the full height of the pane.

**Install**

```yaml
image: ghcr.io/jaredbahr/inkdrop:latest
```

Pin this build with `ghcr.io/jaredbahr/inkdrop:0.1.16`.
