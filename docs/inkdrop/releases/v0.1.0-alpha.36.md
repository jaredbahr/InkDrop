# InkDrop 0.1.0-alpha.36

Manga volume imports now check what is actually inside the archive.

- A CBZ containing one chapter can no longer pass as a volume because its outer filename says `001` or `v01`.
- Real volumes that contain several distinct chapters remain eligible for automatic import.
- Folder scans cannot revive a file that InkDrop already rejected as the wrong unit.
- Historical wrong-unit imports are retracted and their wanted volumes are reopened automatically.
- Healthy pack automation stays out of the way; stalled, failed, and user-blocked work remains visible.
