# Private Alpha Update 25 (0.1.0-alpha.25)

This update closes several gaps between finding a release, starting it, and recognizing that it finished.

- SLSKD search time now starts after local setup, so cache cleanup cannot use up the provider's entire search window.
- Inline Prowlarr, RSS, and MangaDex work uses the same source-worker lock as scheduled work, preventing overlapping database writes and misleading zero-attempt failures.
- A busy source worker now produces an explicit retry instead of looking like an empty search.
- SLSKD keeps the remote directory with each transfer and uses one stable identity for full paths and file-only results.
- Completed files can now be matched back to their original task instead of being duplicated or returned to the queue.
- Regression coverage includes the live Batman: The Killing Joke transfer and the provider-attempt failure seen while searching Gotham Central.
