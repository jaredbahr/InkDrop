# Private Alpha Update 30 (0.1.0-alpha.30)

SLSKD recovery now checks the transfer itself before treating an old download as complete.

- Timed-out and partial transfers are ignored, even when an older InkDrop status label says “succeeded.”
- Exact completed transfers and 100% transfers with no bytes remaining can still be recovered.
- Current ready imports and valid historical recoveries continue to share each bounded batch.
- Added regression coverage using the same transfer shape found during the Alpha 29 deployment check.
