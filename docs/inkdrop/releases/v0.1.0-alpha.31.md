# Private Alpha Update 31 (0.1.0-alpha.31)

Historical SLSKD recovery now requires real completion evidence even when InkDrop has a saved local path.

- Timed-out and failed transfers cannot enter the recovery batch through the normal local-file branch.
- Completed historical transfers still use structured SLSKD state or 100% progress with no bytes remaining.
- Current ready imports keep their existing local-path behavior.
- Added production-shaped coverage for timed-out and failed rows with populated paths.
