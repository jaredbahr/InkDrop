# Private Alpha Update 27 (0.1.0-alpha.27)

Completed SLSKD downloads are now checked in the download folder saved in InkDrop settings.

- InkDrop applies the saved SLSKD provider settings before it tries to recover or import a completed transfer.
- Files under a custom download root, including the Killing Joke file used to reproduce this bug, can now reach the safe path-matching and import flow.
- A missing or invalid SLSKD configuration stops with a clear configuration error instead of silently checking the wrong folder.
- Regression coverage verifies the configured root, exact trailing-path match, import handoff, secret redaction, and fail-closed behavior.
- About now groups Alpha 13–20 into one shorter entry while keeping the recent updates detailed.
