The big one this build: "SLSKD is not working" reports traced to a pipe deadlock giving false timeouts on searches that had already finished successfully. Several other real acquisition-pipeline gaps are fixed alongside it.

- SLSKD probes that had already finished were being logged and retried as timeouts — 374 times in a single day. The probe was blocking on its own stdout; it now writes results to a status file instead. Fixed.
- A candidate with the wrong volume or print run (e.g. "v2 #19" when you wanted "v1 #19") could be auto-grabbed as a safe match. It's now blocked when the mismatch is confirmed, and sent to Manual Review instead of auto-grabbed when your wanted item's print run isn't known yet.
- 149 series (1,186 issues), including every League of Extraordinary Gentlemen issue, were never being searched via SLSKD at all — a broken staleness tiebreak locked late-alphabet series out of the search rotation permanently. Fixed; they'll rotate back in over the next few scheduled passes.
- RSS discovery had been silently stalled for about three weeks by a slow database query, not the feed or the matcher. Fixed, and its System-page status card no longer reports a month-old snapshot as current.
- A wrong-series match now stops retrying after the first rejection instead of re-checking the same downloaded file against the same wanted issue forever — one issue hit this 161 times in a week.
- SLSKD, Prowlarr, Torznab, and Newznab searches all now try a few more query variants on a genuine zero-result search instead of waiting for a future pass to happen to rotate to one that works.
- Manual Review was hiding real "needs you" decisions imported from the legacy review feed — they're visible again, with a new bulk-ignore action for clearing several at once.
- Remapped qBittorrent download folders, paused/verifying downloads misreported as "downloading," and a download client hiccup that could blacklist a good release for 30 days are all fixed.
- The automation status indicator in the header now updates within about 15 seconds instead of up to 75, and pulses while something is actually running.
- The Queue's "waiting on source" panel now names the actual source a row is waiting on, with a plain-English explainer for ComicsCodes.
- Automatic search is now on by default in the closed-alpha install packet, matching every other guided install path — this was the root cause behind some "nothing is happening" reports.
