# InkDrop 0.1.0-alpha.42

- Automatic SLSKD searches now try trusted volume wording such as Band, Tome, Volume, Book, HC, and TPB before the query budget runs out.
- Catalog rows with trusted numbered volume titles are treated as volumes even when the series was broadly stored as a comic.
- Safe cached candidates get a fairer share of each automatic pass instead of waiting behind the wider backlog.
- Exact issue metadata, wrong volumes, ranges, omnibus releases, unrelated titles, and unsafe packs remain blocked.
- A maintained 25-item recall cohort now records automatic/manual parity and the reason for every intentional exclusion.
