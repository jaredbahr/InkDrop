# Private Alpha Update 32 (0.1.0-alpha.32)

Automatic searches now keep moving even when the SLSKD retry backlog is large.

- The default six-series pass gives at most one early slot to a hot SLSKD retry when ordinary searches are waiting.
- At least one series slot stays available for fresh and overdue automatic searches; the default runtime reservation is 180 seconds.
- Oldest-due ordering, duplicate protection, match rules, and download safety gates are unchanged.
- Regression coverage uses a saturated mix of cached SLSKD retries and ordinary retry-due series.
