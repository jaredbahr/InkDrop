# Private Alpha Update 28 (0.1.0-alpha.28)

InkDrop now gives older completed SLSKD downloads another safe chance to import.

- Recovery only considers active automatic wanted items with durable completed-transfer evidence.
- InkDrop uses the saved SLSKD download root and the same bounded exact-path checks added in Alpha 27.
- Each queue gets one newest task winner, so an old record cannot create a duplicate import.
- A newer verified import, rejection, failed transfer, or stalled transfer blocks stale recovery.
- Regression coverage includes the failure patterns seen with Batman: The Killing Joke, Descender, Fullmetal Alchemist, and Gotham Central.
