# Private Alpha Update 26 (0.1.0-alpha.26)

SLSKD downloads can now finish cleanly when the remote user's folder layout does not match InkDrop's local download folder.

- InkDrop checks a small, fixed set of exact trailing path matches beneath the configured SLSKD download root.
- A remote path such as `Comics/DC/(1988) Batman - The Killing Joke/file.cbz` can match the unique local `(1988) Batman - The Killing Joke/file.cbz`.
- The search is bounded to 16 suffix checks and never recursively crawls the download tree.
- InkDrop refuses ambiguous matches instead of choosing between two files with the same valid suffix.
- Absolute paths, traversal, overlong remote paths, basename collisions, and symlink escapes remain blocked.
