# Private Alpha Update 29 (0.1.0-alpha.29)

Completed SLSKD downloads no longer have to wait behind failed historical transfers.

- Current ready imports and trustworthy completed SLSKD recoveries share each bounded batch.
- Timed-out, partial, and failed historical transfers are filtered before the batch limit.
- Pending SLSKD retry maintenance runs after eligible import work and keeps a small reserved slot.
- Queue-level duplicate, verified-import, rejection, and terminal-failure safeguards remain in place.
- Stress coverage mixes 80 ready, completed, and partial records to verify that useful work keeps moving.
