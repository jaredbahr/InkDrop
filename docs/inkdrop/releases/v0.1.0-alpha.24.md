# Private Alpha Update 24 (0.1.0-alpha.24)

Automatic search now spends its time on the queries most likely to find a usable release, and older wanted items can no longer sit behind fresh additions forever.

- SLSKD starts with broad series and collected-title searches before narrowing to an exact issue or volume.
- Prowlarr, Torznab, and Newznab use the same broad-first approach.
- Delayed SLSKD peer results get a bounded polling window instead of being discarded too early.
- Series folders and packs feed the existing safe multi-issue coverage checks, so one useful source can satisfy several wanted issues.
- Every scheduler pass reserves room for old retry-due work as well as newly added series.
- Retry ordering uses the oldest promised retry time, and the bounded pass size increases from three series to six.
- Regression coverage includes Batman: The Killing Joke, Descender, Fullmetal Alchemist, Gotham Central, and Court of Owls.
