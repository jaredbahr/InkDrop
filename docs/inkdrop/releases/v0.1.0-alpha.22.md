# Private Alpha Update 22 (0.1.0-alpha.22)

This update cleans up InkDrop's GitHub page and makes GitHub Releases part of the normal validated QA build.

- The project page now leads with a clear overview, supported integrations, storage needs, and practical setup guidance.
- It clearly explains that the web app and worker are two containers using the same image, and that InkDrop does not update itself automatically.
- The default `main` branch is identified as older source, not the current QA installation channel.
- The image, candidate manifest, About page, Git tag, and GitHub prerelease now use one checked-in version and release note.
- A Release is created only after the exact pushed image passes identity, preflight, container-health, and HTTP checks.
- Each GitHub prerelease preserves the verified commit and immutable image digest in its body and attached evidence files.
- Releases stay marked as prereleases. Existing matching releases can be updated safely, but a tag at another commit is never rewritten.
- Feature branches and pull requests never create a GitHub release.
