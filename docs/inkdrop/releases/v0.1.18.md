## InkDrop 0.1.18

Most of this release is about books InkDrop found and then could not keep: a
file from another volume could satisfy the wrong book, stale issue totals
could close the wrong unit, and automatic covers were not added to new
imports.

**If books are being marked present when the file belongs somewhere else, take this one.**

**What stopped working before**

- **A file from another volume no longer satisfies a book.** A same-title file
  from a newer or different volume, or a file whose name identifies another
  work, could close the wrong unit. Proofs now need the target work, volume and
  folder to agree.
- **An issue total is no longer read as the issue number.** Names such as
  `#1 (of 12)` could make issue 1 stand in for issue 12. Stale proofs created
  from that reading are retracted, and the affected book is searched again.
- **A wrong import proof no longer returns after a queue sync.** Refusals for
  another work's file are applied at each path that can mark a book satisfied,
  and a refused proof is recorded once rather than once per pass.

**Finding the right book**

- **A file's own number beats the folder it sits in.** Range folders and pack
  spans no longer override an issue number in the filename, while a file's
  issue stem is used inside volume folders.
- **A manga volume is offered volume files from Soulseek.** Volume targets no
  longer receive chapter files that will later be refused.
- **A second copy is not mistaken for an existing valid archive.** A corrupt,
  truncated or unreadable canonical file is preserved while the good download
  gets a new name; valid archives still prevent an unnecessary duplicate.
- **New imports receive a front cover when the series has one.** Cover
  injection runs on successful automatic imports, handles changed covers and
  shared folders, and reports refused changes. A one-time sweep also added a
  front cover as page one to the first archive of 136 series; originals were
  kept.

**Downloads and clients**

- **A stuck Soulseek transfer no longer consumes retries on every pass.** A
  post-transfer filename mismatch is bounded, and a re-observed stuck transfer
  counts once toward the retry ceiling instead of looping indefinitely.
- **Automatic Search no longer waits on a handoff that will not clear.** The
  stall clock follows the oldest pending handoff, so a newer change cannot
  keep resetting the wait.
- **The precise comic search gets its turn.** Searches naming both a series and
  issue now compete with broad series searches instead of being left behind.

**Searching**

- **Chapter links stay in the chapter lane.** MangaDex rows keep their chapter
  identity even when another provider label is present, refreshes count
  distinct chapters rather than scanlation rows, and only chapters beyond the
  newest owned volume are wanted.
- **A book reopened by a failed import check can be grabbed again.** Its old
  completion record no longer blocks the next search.

**The review queue**

- **A review row keeps the reason it was refused.** Bulk actions name failed
  items and their reasons, and a section error no longer blanks the rest of
  the page.
- **A list shows the answer to the last request.** Fast filter changes no
  longer let an older response replace the newer one; deferred-sync status also
  keeps its totals separate from its bounded detail list.

**Settings and backup**

- **A zero in notification settings stays zero.** Fractional whole-number
  settings and impossible quiet-hours values are refused instead of rounded or
  silently ignored.
- **Backup downloads and configuration exports require the right access.**
  Read-scoped keys cannot list or download backup archives, and exported
  settings omit unknown environment values and credentials embedded in URLs.
- **A config folder with a space in its path works.** Startup no longer splits
  one path into two.
- **A restore that is refused leaves the database untouched.** Restoring a
  backup now copies into the live database through SQLite's own backup, keeps
  each database's journal mode, and puts back anything it changed if a later
  step fails. It also refuses while a background job is running instead of
  racing it.

**Install**

```yaml
image: ghcr.io/jaredbahr/inkdrop:latest
```

Pin this build with `ghcr.io/jaredbahr/inkdrop:0.1.18`.
