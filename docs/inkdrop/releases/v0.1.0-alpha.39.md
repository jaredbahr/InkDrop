# InkDrop 0.1.0-alpha.39

- History now shows download, import, and verification results instead of the raw search event trail.
- Blocklist is a separate Activity page for releases InkDrop flagged as bad and will avoid automatically.
- History queries use indexed lifecycle records, keeping global and series-specific views responsive as the event database grows.
- Series and issue History keeps linked grabs, downloads, imports, failures, and verification even when the original event did not store the series directly.
- Raw provider and search events remain available under Diagnostics > Event Trail.
