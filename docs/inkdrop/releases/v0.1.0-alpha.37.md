# InkDrop 0.1.0-alpha.37

- Authoritative manga metadata now distinguishes chapters from complete volumes before an archive can satisfy wanted work.
- Archive identity and decoded page evidence must agree with the expected issue, chapter, or volume.
- Every manga CBZ page must pass image validation; corrupt, empty, or truncated archives fail closed.
- Outer filenames can no longer make a single chapter look like a complete volume.
- `.cbz`, `.cbz.zip`, and supported plain `.zip` archives now follow the same verification and normalization rules.
- Verified legacy manga archives normalize to reader-safe CBZ names before Kavita scans them.
